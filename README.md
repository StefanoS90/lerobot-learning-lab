# lerobot-learning-lab

A playground to experiment with LeRobot imitation learning concepts — training and evaluating manipulation policies, and writing down what I actually learn along the way.

Each numbered folder is one experiment/chapter, with its own write-up and any scripts it used.

4. [Language: one model, several tasks](04-language-multitask/README.md)
